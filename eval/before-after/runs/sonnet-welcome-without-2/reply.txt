- **Cause:** the regex in `tinyparse/size.py` captured only the integer part of the number, so `"1.5k"` was read as `1k`.
- **Fix:** the regex now captures the whole number, and the multiplication uses `Fraction` so there's no float rounding. `parse_size("1.5k")` now returns 1536. The result is still an `int`, so a fractional byte is truncated (`"1.5"` gives 1).
- **Tests:** I added cases for `"1.5k"`, `"1.5M"` and `"0.5 KiB"`. All 7 tests in the suite pass.
